# About this copy

This is the public portfolio copy of a private, running system. The athlete's personal data (training history, health metrics, logs, locations) is not included: the `brain_*` files are **sample data** that show the format. The code, tests, rulebook and architecture are the real ones, with names and places generalised. Some files the docs mention (legacy scripts, the archive, the real athlete files) exist only in the private repo. Generated by a private export script.
