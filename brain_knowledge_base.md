# Athlete Knowledge Base (SAMPLE)

The public copy ships this template instead of the real athlete file. In the private
deployment this file holds the athlete's profile, goals, injuries, gear and personal rules;
the coach reads it every session. The rules below show the structure with illustrative values.

## 0. Preferences
- Runs outside by default; treadmill when the weather or the schedule says so.
- Treadmill workouts are time-based with belt speeds (the watch under-reads treadmill distance).
- Asks before planning Thursday–Sunday whether the athlete will be in the home town or the work city.
- No floor-only gym trips: core work is folded into lifting days.

## 3. Personal rules (examples of the format)
- **Rule 5, fatigue-resistance long runs:** fast-finish every 2–3 weeks; marathon-pace segments
  in the alternate week; never a heavy leg day within 72 h before a long run.
- **Rule 10, strength:** main lifts 3–6 reps at RPE 8–9, accessories 6–12, 8–12 hard sets per
  muscle per week; rests 2:30 heavy compounds, 2:00 other hard sets, 1:00–1:30 isolation.
- **Rule 11, HRV gate (option B):** no Zone 4/5 when last night's HRV is below Garmin's
  balanced-low and either the 7-day average is below it or resting HR is 5+ bpm above normal.
- **Rule 12, eat-what-you-can adjustments:** low energy availability before a key session →
  add carbs; two or more low days → swap to easy.

## 4. Goals (illustrative)
- Run faster and longer; stay ~4–6 weeks from race shape ("90% ready").
- Half marathon 1:40 → 1:35 → 1:30; marathon sub-3:30, then sub-3.
- Secondary: get stronger without adding much mass.
